Reports a positional, splat, double-splat, out, or heredoc argument after a named argument. Crystal rejects anything but another named argument once the named phase starts.

Example: f(a: 1, 2) is invalid; the trailing argument must be named (f(a: 1, b: 2)). Block passes (&blk) and do blocks stay allowed after named arguments, as do macro-controlled tails whose expansion is unknown. Spaced-colon type shapes (x : Type) never open the named phase.
