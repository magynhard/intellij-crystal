Reports a required positional parameter declared after an optional positional parameter. Crystal requires every parameter after an optional positional parameter to declare a default value.

Example: def foo(a = 1, b) is invalid; b must declare a default (def foo(a = 1, b = 2)). Parameters after a bare * or a splat are named-only and may still be required (def foo(*a, b) and def foo(*, b)).
